# Remise en forme (app web installable)

Application autonome : aucun compte, aucun serveur, données stockées sur le téléphone.

## Mettre en ligne (une seule fois)
N'importe quel hébergeur de fichiers statiques en HTTPS convient. Avec GitHub Pages :
1. Crée un dépôt public, par exemple `forme`, et dépose-y tout le contenu de ce dossier.
2. Dans le dépôt : Settings > Pages > Source « Deploy from a branch », branche `main`, dossier `/ (root)`.
3. L'adresse devient `https://<ton-compte>.github.io/forme/`.

## Installer sur l'iPhone
1. Ouvre l'adresse dans Safari.
2. Bouton Partager > « Sur l'écran d'accueil ».
3. Lance l'app depuis son icône : elle s'ouvre en plein écran et fonctionne hors ligne.

## Sauvegarde
Réglages > Sauvegarde > « Enregistrer une sauvegarde » > « Enregistrer dans Fichiers » > iCloud Drive.
L'app le rappelle au bout de 7 jours. Supprimer l'icône efface les données locales.
